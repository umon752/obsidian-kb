# hyphens   
- [Can I use](https://caniuse.com/?search=hyphens)   
- [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/hyphens)   
- [CSS-TRICKS](https://css-tricks.com/almanac/properties/h/hyphenate/)   
   
   
範例：   
```
body {
	overflow-wrap: break-word; // 解決長單字、長網址不換行的問題
	hyphens: auto; // 單字換行時更自然、有語意地切斷
}

```
