# oklch()   
- [Can I use](https://caniuse.com/?search=oklch())   
- [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/color_value/oklch)   
- [CSS-TRICKS](https://css-tricks.com/almanac/functions/o/oklch/)   
- [Youtube](https://www.youtube.com/watch?v=VA975GOUFmM&list=PLJB7raOkjDTys6zxVGr9Kr_EUXX3eaRMT&index=63)   
   
   
此函數在 [CIE Lab 色彩空間](https://en.wikipedia.org/wiki/CIELAB_color_space)（源自 OKLAB 的圓柱模型） `oklch()` 中運作。它旨在修復舊空間的缺陷，例如（色域有限）和（感知不均勻）。   
範例：   
```
color: oklch(亮度 (L), 色度（C）, 色調 (H), Alpha 透明度（可選）)
```
