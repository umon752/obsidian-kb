# hook   
React Hook 是與 React 的元件生命週期與畫面狀態綁在一起的函式，而一般函式只是單純處理資料的邏輯工具。   
React Hooks 只能在以下兩種地方呼叫：   
- React 函數元件的頂層   
- 自訂 Hook 的頂層   
   
   
## hook vs 一般函式   
## 🧠 核心差異簡介   
|                          類型   <br> |                                               React Hook   <br> |                                                  一般函式方法   <br> |
|:-----------------------------------|:----------------------------------------------------------------|:---------------------------------------------------------------|
|                  是否依賴 React   <br> |                        ✅ 只能用在 React Function Component 裡   <br> |                                     ❌ 可用於任何地方（如工具、邏輯處理）   <br> |
|                   是否會影響畫面重繪   <br> |                                           ✅ 會影響狀態更新與畫面重繪   <br> |                                            ❌ 不會主動觸發畫面變化   <br> |
|                      有無記憶狀態   <br> |                        ✅ 可透過 `useState`、 `useEffect` 等管理   <br> |                                            ❌ 不具備記憶狀態的能力   <br> |
|                        使用限制   <br> |                                     ✅ 只能在最上層呼叫，不可在迴圈/條件內   <br> |                                                  ❌ 沒有限制   <br> |
|                        使用時機   <br> |                                       用來操作 UI 狀態、生命週期、事件   <br> |                                        用來處理資料邏輯、轉換、工具函式   <br> |
