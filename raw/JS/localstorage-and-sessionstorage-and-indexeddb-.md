#  localStorage & sessionStorage & IndexedDB (儲存方式)   
## IndexedDB   
在瀏覽器中儲存大量結構化資料的 API，它屬於 **前端離線儲存技術**，適合用來儲存複雜或大量資料，例如物件、JSON 結構、Blob 等，並支援索引與查詢。   
   
### 使用情境   
- **離線應用（Offline Web Apps）**
當應用需要在沒有網路的情況下也能正常運作（PWA 或離線模式），會將資料儲存在 IndexedDB，使用者下次上線時再同步資料。
範例：離線筆記本、離線地圖、To-Do App。   
- **大量資料快取（Local Caching）**
為了減少 API 請求、提升效能，可以將伺服器回傳的資料儲存在 IndexedDB 中，下次使用時可直接讀取。
範例：查詢結果快取、圖片資料快取、商品清單等。   
- **複雜資料結構儲存**
`localStorage` 只能儲存字串且容量有限，而 IndexedDB 支援物件、Blob，適合儲存複雜結構的資料。
範例：儲存使用者偏好設定（以物件形式儲存）、表單草稿、自訂配置等。   
- **資料同步（Data Sync）**
搭配 Background Sync 或定時任務，先暫存資料到 IndexedDB，待網路恢復時再同步到伺服器。
範例：填寫表單時中斷連線、留言功能、儲存用戶上傳資料後再補上傳。   
- **漸進式 Web App（PWA）**
使用 Service Worker 結合 IndexedDB 可實現離線資源管理與資料儲存，是打造離線體驗的重要技術。
範例：離線閱讀、播放音樂或影片。   
- **複雜查詢 / 索引**
IndexedDB 支援建立索引，讓你可以針對資料欄位查詢、排序，非常適合需要搜尋或分類資料的應用。
範例：本地搜尋功能（如搜尋產品名稱、分類）。
