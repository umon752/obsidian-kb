# Skill 實戰教學

## 核心要點

- Skill 的價值是把人類的執行邏輯與領域知識轉成 agent 可重複使用的工作流程。
- 以漸進揭露組織內容：先讀 `SKILL.md`，再依需要載入 references，最後執行 scripts 或工具。
- 適合抽象成 skill 的訊號包括工作反覆出現、需要專業領域知識，以及錯誤代價高。
- 以原則取代過度僵化的 SOP，並控制主文件與參考文件的長度，降低上下文負擔。
- 維護可分為觀察實際使用、修正指令與案例、再以評估結果驗證；應採 evaluation-driven development。
