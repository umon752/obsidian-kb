# CSS counter()

## 核心要點

- `counter-reset` 建立或重設計數器。
- `counter-increment` 在指定元素出現時遞增計數器。
- `counter()` 可搭配偽元素的 `content` 顯示序號，例如自動編號標題。
- 原始範例示範在 `h2::before` 輸出計數結果。
