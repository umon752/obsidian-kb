# GEO（Generative Engine Optimization）

## 核心要點

- 文章頁可在文末加入 3–5 個完整 FAQ，增加生成式 AI 理解與引用的機會。
- Google 商家資料應完整填寫、上傳照片，並在簡介中放入核心服務關鍵字，以提升可信度與可見度。
- 素材記錄 Lighthouse 13.3 新增 Agentic Browsing 類別，檢查 `llms.txt`、WebMCP、Accessibility Tree 與 CLS。
- Google Search 團隊與 Lighthouse 團隊對 `llms.txt` 的定位不同：前者暫不將其作為排名因素，後者將它視為 Agent Ready 的可選檢查項目。
- GEO 的目標是讓 AI Agent 更容易理解、引用與操作網站，不等同於傳統 SEO 排名優化。
