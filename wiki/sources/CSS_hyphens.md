# CSS hyphens

## 核心要點

- `hyphens: auto` 允許瀏覽器依語意在單字換行時加入適當斷點。
- `overflow-wrap: break-word` 可處理長單字或長網址溢出容器的情況。
- 兩者搭配能兼顧不溢出與較自然的文字斷行。
