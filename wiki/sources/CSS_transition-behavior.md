# CSS transition-behavior

## 核心要點

- `transition-behavior` 用於控制離散 CSS 屬性是否參與 transition。
- 主要應用方向是讓 `display: none` 等狀態變更能搭配動畫表現。
- 原始素材註明當時瀏覽器支援度仍需確認，不能直接假設所有環境可用。
