# CSS resize

## 核心要點

- `resize` 控制可調整尺寸元素的拖曳方向。
- `textarea { resize: none; }` 可禁止使用者拖曳改變文字區域大小。
- 素材包含 MDN、Can I Use 與 CSS-Tricks 參考。
