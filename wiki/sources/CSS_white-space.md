# CSS white-space

## 核心要點

- `white-space` 主要控制空白字元與換行的保留方式。
- 選擇值時需依內容是否允許自動折行、是否保留原始換行來決定。
- 原始素材僅留下主題名稱，尚未記錄各取值範例。
