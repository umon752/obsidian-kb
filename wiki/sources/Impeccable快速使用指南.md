# Impeccable 快速使用指南

## 來源資訊
- 原始素材：`raw/AI/impeccable-quick-guide.md`
- 本頁依素材整理指令用途；實際可用指令及行為以目前安裝版本為準。

## 核心要點
- 初次整理專案時，`/impeccable init` 建立產品背景 `PRODUCT.md`，`/impeccable document` 整理視覺規則至 `DESIGN.md`。
- 依工作選擇 `shape` 規劃方向、`layout` 調整版面、`typeset` 處理文字，或使用 `bolder`、`quieter`、`colorize`、`animate`、`distill` 調整視覺表現。
- `critique` 用於檢討設計，`polish` 用於細節精修，`audit` 檢查無障礙、響應式與效能議題。
- 素材建議在會直接修改專案的指令前建立 Git 檢查點，執行後查看差異；`live` 可用於互動式局部調整。
