# CSS box-shadow

## 核心要點

- 外陰影直接使用 `box-shadow` 的偏移、模糊、擴散與顏色值。
- 加上 `inset` 可將陰影繪製在元素內部。
- 多組陰影可用逗號串接，組合不同方向與明暗效果。
