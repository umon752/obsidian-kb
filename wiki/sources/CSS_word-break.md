# CSS word-break

## 核心要點

- `word-break` 控制單字內部是否可以斷開字元。
- 原始素材指出它可在任意情況下影響文字斷行，但未留下取值範例。
- 實作時應和 `overflow-wrap`、`white-space` 一起評估長字串的排版需求。
