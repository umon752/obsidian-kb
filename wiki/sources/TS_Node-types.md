# TypeScript 使用 Node.js 型別

## 核心要點

- 在 TypeScript 專案安裝 `pnpm add -D @types/node`，補上 Node.js API 的型別定義。
- 適合解決使用 Node.js 全域或模組時，編輯器出現找不到型別的錯誤。
- 素材另附設定畫面截圖，實際錯誤仍應依專案的 module resolution 與 tsconfig 檢查。
