# CSS overflow-wrap

## 核心要點

- `overflow-wrap` 的舊名稱是 `word-wrap`。
- `overflow-wrap: break-word` 會在內容超出容器時允許長單字或長網址換行。
- 可搭配 `hyphens: auto` 改善換行的語意與視覺效果。
