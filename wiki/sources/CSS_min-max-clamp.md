# CSS min()、max()、clamp()

## 核心要點

- `min()` 回傳候選值中的最小值，`max()` 回傳最大值。
- `clamp(min, preferred, max)` 將尺寸限制在最小與最大值之間。
- `clamp()` 可把 `vw` 與 `rem` 組合，建立不依賴大量 breakpoint 的流動字級或寬度。
