# CSS scroll-snap-type、scroll-snap-align

## 核心要點

- `scroll-snap-type` 設定捲動容器的軸向與捕捉策略，例如 `x mandatory`。
- `scroll-snap-align` 設定子元素停留時要對齊的位置，例如 `center`。
- 常見應用是可橫向捲動的卡片列表，讓捲動停止在卡片位置而非 free mode。
