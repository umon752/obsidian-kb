# TanStack

## 核心要點

- TanStack Query 可快取 AJAX 結果，資料未變更時優先讀取快取，減少重複請求。
- TanStack Router 可採目錄路由，或用檔名在同層宣告 flat routes。
- 素材另外列出 Virtual 與 Form 能力，前者處理大量列表，後者可依 schema 生成與驗證表單。
