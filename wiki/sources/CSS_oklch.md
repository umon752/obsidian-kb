# CSS oklch()

## 核心要點

- `oklch()` 以 OKLAB 的圓柱模型表示色彩。
- 參數概念為亮度（L）、色度（C）、色調（H），並可選擇 alpha 透明度。
- 素材指出它用於改善舊色彩空間的色域與感知均勻性問題。
