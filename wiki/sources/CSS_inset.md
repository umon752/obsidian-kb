# CSS inset

## 核心要點

- `inset` 是定位元素 `top`、`right`、`bottom`、`left` 的 shorthand。
- 適合與 `position: absolute` 或 `position: fixed` 搭配使用，縮短四邊定位宣告。
- 素材包含 MDN、Can I Use、CSS-Tricks 與影片參考。
