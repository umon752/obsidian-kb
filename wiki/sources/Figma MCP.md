## 核心要點

- Figma Dev Mode MCP Server 可將設計稿脈絡提供給 AI 工具使用。
- 素材包含官方文件與 VS Code remote server 安裝說明。
- 在 VS Code 輸入 `@mcp` 可查看目前可用的 MCP 工具。
- 另收錄 Figma、GitHub Copilot、Cursor 與設計轉程式碼的延伸文章。
