# CSS overscroll-behavior

## 核心要點

- 素材檔名為 `overflow-behavior`，參考連結實際指向 CSS `overscroll-behavior`。
- 此屬性可控制元素滾動到邊界時是否將滾動傳遞給祖先容器，以及過度滾動效果。
- 使用前應以 MDN 與瀏覽器支援度確認正式屬性名稱。
