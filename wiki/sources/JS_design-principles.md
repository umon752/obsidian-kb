# JavaScript 設計原則

## 核心要點

- YAGNI：沒有實際需求時不要預先實作可能永遠用不到的功能。
- Rule of Three：相同功能重複出現三次，再抽成共用實作。
- 以低耦合、關注點分離與 Clean Code 降低維護成本。
- 素材建議每個檔案控制在約 100–200 行，讓責任範圍容易理解。
